## Zhoda so zadaním
- Model `deepseek-flash` existuje (GET `/models` s naším kľúčom: `"id":"deepseek-flash"`, `"name":"DeepSeek-V4.1-Flash"`); pricing: „Use deepseek-flash as the model name“.
- Search: `POST https://api.deepseek.com/v1/tools/search`, Fetch: `POST https://api.deepseek.com/v1/tools/fetch` (https://api-docs.deepseek.com/guides/search/). Polia Search: `query` (1–128 znakov), `count` (1–50, predvolene 10), `need_content`, `ori_question`, `localization`. Operátory `site:`, `-site:`, `lang:`, `after:` atď. sú podporené. Fetch: `url` → `{title, content}` (Markdown).
- JSON mode: `response_format: {"type": "json_object"}`, v prompte slovo „json“ a príklad (https://api-docs.deepseek.com/guides/json_mode/).
- Tool calls: formát OpenAI `tools`, vykonáva náš kód; non-thinking cez `"thinking": {"type": "disabled"}` (https://api-docs.deepseek.com/guides/tool_calls/).
- **Rozdiel:** žiadny vecný. Jediné spresnenie: dotaz Search má limit 128 znakov, prípona `-site:ra.co -site:instagram.com` (32 znakov) ho skracuje.
